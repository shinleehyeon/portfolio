## 고유 키워드

**데이터로 맥락을 읽는 프론트엔드**

다른 지원자와 겹치지 않게 한 줄만 가져간다. 화면을 먼저 만들지 않고, 이탈·회피·대기 지점을 데이터로 본 다음 고친다는 뜻이다.

- 당근: BigQuery로 신고 회피 패턴 → FDS
- EffectGen: Mixpanel 이벤트를 먼저 깔고 개선
- SLOP: 생성 지연을 폴링으로 놓치지 않음

이력서 한 줄, 자소서 전 문항에 이 키워드만 반복한다. "열정", "최연소", "도전"은 쓰지 않는다.

## 쓰는 순서

1. 템플릿에 `01` 경력·스택·수상을 그대로 옮긴다. 서술형으로 풀지 않는다.
2. 지원 회사가 티빙이면 `02`를 그대로 낸다.
3. 회사가 바뀌면 `02`를 그 공고 키워드로 다시 쓴다. 경력 팩트는 `01`을 재사용한다.
4. 확인 안 된 연월·수치는 `03`을 보고 고친다.
